## 系统与运行说明

LMC-5 为本团队开发的五维记忆系统，采用 X 时间线、Y 关系网、Z 事实演化、E 体验信号、M 记忆代谢的架构。设计参考与致谢见公开仓库 docs/credits.md。

重排层可按需适配 Luna、JEV、Clef，使用者需自行配置对应服务的 API 密钥，项目不提供共享密钥或共享调用额度。当前参赛默认使用 JEV；本参赛分支只保留 JEV 实现，Luna 与 Clef 需另接适配器。

本次参赛版本为 v0.3.0-aml.1，基于 LMC-5 0.3.0 核心，包含公开的 AML HTTP 接口和 JEV 重排桥接层；原始报名快照含预算账本，当前源码已移除。已部署同步 Add、Search 和健康检查接口，地址见表单；Add/Search 使用 Authorization: Bearer 鉴权，服务常驻并配置开机自启。

考场实例使用按用户隔离的 SQLite 存储，支持相同 request_id 与请求内容的顺序重试幂等。检索采用词法与向量召回、RRF 融合及第三方 JEV 重排。向量模型为 DashScope text-embedding-v4；重排服务由 TypeSafe 提供，模型为 jev-1.13.0。JEV 最多处理 100 个候选，最终返回不超过 min(top_k, 50) 条；召回条数仍受请求 top_k 和可检索内容影响。结果按需附带同会话相邻轮次，并按时间或当前事实查询意图排序。

JEV 单次检索调用并发上限为 16，默认进程级 JEV 调用并发上限为 16，单请求体上限为 8 MB。这里的并发限制指重排调用，不代表已验证的 HTTP 客户端并发容量。当前源码不设置本地 JEV 费用上限、不要求计费账本，实际费用以供应商账户为准。调用失败时当前检索回退到 RRF；保留超时、并发控制、供应商 Retry-After 和有限冷却，不留下永久停线。

接口源码、重排适配、配置模板、启动步骤、离线联测见 extras/aml/README.md；该参赛快照对应标签 v0.3.0-aml.1。公开代码不包含真实密钥、记忆数据或评测数据集。JEV 为第三方服务，本项目不声明其模型为自研。基础开源核心的全部可选能力不等于本次考场全部启用能力；多跳实验与拒答阈值默认关闭。
